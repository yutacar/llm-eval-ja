このフォルダ（カレントディレクトリ）には、three.js のボクセルで作った「五重塔のある庭」があります（pagoda-gen.js、index.html、check.mjs）。
まず3つのファイルを読んで仕組みを理解してから、「雪景色モード」を追加してください。

【pagoda-gen.js】
1. build に引数 options を追加し、build({ snow: true }) で雪景色のデータを返すようにする。
   build() と build({}) の結果は、今とまったく同じにすること（既存のブロックの位置・色・数を一つも変えない）
2. 雪景色では、garden と pagoda のブロックのうち「y が 0 以上で、真上（y+1）に何も無い」ものの真上に、
   白い雪のブロック（#f4f6fa）を1段だけ置く。雪は新しいレイヤー snow に入れる。水面（water）の上には置かない。
   それ以外のレイヤーの中身は通常と同じにする
3. ファイルの最後の globalThis.PAGODA = build(); はそのまま残し、その次の行に globalThis.PAGODA_SNOW = build({ snow: true }); を追加する

【index.html】
4. S キーで雪景色と通常を切り替える（雪景色では PAGODA_SNOW を描く）。雪景色では空と霧を灰色寄りにし、雪が舞い落ちるパーティクルを表示する
5. 左上の操作説明に「S: 雪景色」を追加する。0〜3 の視点切り替えは今までどおり動くこと

【check.mjs】
6. 今までの確認に加えて、雪景色の確認を足す: snow レイヤーのブロック数を表示し、真下にブロックが無い雪（宙に浮いた雪）があれば ERROR

守ること:
・このフォルダの外のファイルは読まない・変更しないこと
・最後に node check.mjs を実行し、ERROR が無く OK になることを確認してから、変更点を報告して終了すること
