このフォルダ（カレントディレクトリ、今は空）に、家計簿 CSV を集計するコマンドラインツール kakeibo.py を作ってください。
Python 3 の標準ライブラリだけを使い、1ファイルにまとめること。仕様は次のとおり。出力の形式は一字一句このとおりにすること。

【入力 CSV】
・UTF-8（先頭に BOM が付いていてもよい）。1行目は見出し行 date,category,amount,memo
・date は YYYY-MM-DD。amount は整数で、"1,200" のように引用符付きでカンマを含むことや、-500 のようなマイナス（返金）がある
・memo は空でもよく、引用符付きでカンマを含むこともある
・不正な行（date が実在する日付でない、amount が整数でない、category が空）は飛ばし、標準エラーに「skip line N: 理由」と出す。N はファイルの行番号（見出し行が 1）。終了コードは 0 のまま

【コマンド】
1. python3 kakeibo.py summary FILE [--month YYYY-MM]
   カテゴリごとの合計を「カテゴリ<TAB>合計」で1行ずつ。合計の大きい順、同じ合計ならカテゴリ名の昇順（Python の文字列比較）。
   最後に「合計<TAB>全体の合計」。--month を付けるとその月だけ。該当する行が無ければ「合計<TAB>0」だけ
2. python3 kakeibo.py monthly FILE
   月ごとの合計を「YYYY-MM<TAB>合計」で、月の古い順に
3. python3 kakeibo.py top FILE N
   金額の大きい順に N 件を「YYYY-MM-DD<TAB>カテゴリ<TAB>金額<TAB>メモ」で。同じ金額なら日付の古い順、それも同じならファイルの順。
   N が行数より多ければ全件。N が 1 以上の整数でなければ標準エラーにメッセージを出して終了コード 2

【共通】
・数字はカンマなしの整数で出力
・FILE が無いときは標準エラーに「error: file not found: FILE」と出して終了コード 1
・コマンドが不正なときは終了コード 2

自分でテスト用の CSV と、unittest のテスト（test_kakeibo.py）も作り、python3 -m unittest -v が通ることを確認してから、作ったものを報告して終了すること。
