# minishop

小さなネットショップ用の計算ライブラリ。

- `money.py`  : 円の端数処理（四捨五入）と消費税（食品 8%、それ以外 10%）
- `cart.py`   : 買い物かご
- `discount.py`: クーポン（PCT10 = 10% 引き、YEN500 = 3,000 円以上で 500 円引き）
- `paginate.py`: 一覧のページ分け（ページは 1 から数える）
- `dates.py`  : 「2026年3月4日」「2026/03/04」形式の日付の読み取り
- `csvio.py`  : 注文 CSV の読み込み

テスト: `python3 -m unittest -v`
