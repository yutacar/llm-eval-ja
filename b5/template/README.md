# minical

小さな電卓言語のインタプリタ。`minical.evaluate(src)` が最後の文の値を返す。

## 文法
- 文は改行か `;` で区切る。値は最後の文の値。空の入力は `None`
- 数: `12`、`3.5`、`.5`、`1e3`、`2.5E-2`（小数点や指数を含むと float、それ以外は int）
- 変数: 名前は英字か `_` で始まり、英数字と `_` が続く（例: `x1`、`total_2`）。`x = 式` で代入（代入文の値は代入した値）
- 未定義の変数を使うと `EvalError`
- 関数: `abs(x)`、`max(a, b, ...)`、`min(a, b, ...)`（引数は1個以上）。未知の関数は `EvalError`

## 演算子（強い順）
1. `^` べき乗。**右結合**（`2^3^2` は `2^(3^2)` = 512）
2. 単項の `-` と `+`（`-2^2` は `-(2^2)` = -4）
3. `*`、`/`、`//`、`%`（左結合）
4. `+`、`-`（左結合）

- `/` は常に float
- `//` は **0 に向かって切り捨て**る整数除算（C 言語と同じ。`-7 // 2` は -3）
- `%` は `a == (a // b) * b + a % b` を満たす余り（`-7 % 2` は -1）
- 0 で割ると（`/`、`//`、`%` とも）`EvalError("division by zero")`

テスト: `python3 -m unittest -v`
