# jpdata の仕様

日本のデータを扱う関数を4つの部品に分けて作る。外部のライブラリは使わない（Python の標準ライブラリだけ）。

## 1. jpdata/normalize.py — `normalize(s: str) -> str`

次の順に変換した文字列を返す。**これ以外の変換はしない**（`unicodedata.normalize("NFKC", ...)` をそのまま使うと、①や㈱まで変わってしまうので不可）。

1. 全角の英数字・記号（U+FF01〜U+FF5E）を半角に、全角スペース（U+3000）を半角スペースにする
2. 半角カタカナを全角カタカナにする。濁点・半濁点はまとめる（`ｶﾞ`→`ガ`、`ﾊﾟ`→`パ`、`ｳﾞ`→`ヴ`）。半角の長音 `ｰ` は `ー`、`｡｢｣､･` は `。「」、・` にする
3. 数字（0〜9）に前後を挟まれたハイフンのような文字（`‐ ‑ ‒ – — ― − ー`）を `-` にする。カタカナの長音など、数字に挟まれていない `ー` はそのまま
4. 続いた空白は1つにまとめ、前後の空白を取る

## 2. jpdata/wareki.py — 和暦と西暦

元号と始まりの日（グレゴリオ暦）:

| 元号 | 始まりの日 |
|---|---|
| 明治 | 1868-01-01（ただしこのモジュールが扱うのは 1873-01-01 以降。それより前は ValueError） |
| 大正 | 1912-07-30 |
| 昭和 | 1926-12-25 |
| 平成 | 1989-01-08 |
| 令和 | 2019-05-01 |

- `to_seireki(text: str) -> str`: `"令和元年5月1日"` を `"2019-05-01"` にする
  - 年は数字か「元」。全角数字も受け付ける（先に normalize() する）。「1年」と「元年」はどちらも可
  - 存在しない日付（2月30日など）、その元号の期間外の日付（`平成31年5月1日`、`昭和64年1月8日` など）、0年、知らない元号は ValueError
- `to_wareki(d) -> str`: `datetime.date` か `"YYYY-MM-DD"` の文字列を `"令和元年5月1日"` の形にする
  - 1年は「元年」と書く。月日に0を付けない。1873-01-01 より前は ValueError

## 3. jpdata/address.py — `split_address(s: str) -> tuple[str, str, str]`

住所を（都道府県, 市区町村, 残り）に分ける。先に normalize() してから分ける。

- 都道府県: 47都道府県のどれかで始まればそれ。始まらなければ `""`（`"京都市..."` は京都府ではなく `""`）
- 市区町村:
  - 政令指定都市は区まで含める（`横浜市中区`、`大阪市北区`、`さいたま市浦和区`）
  - 東京都の23区は区（`千代田区`）
  - 郡がある場合は郡から町村まで（`虻田郡倶知安町`）
  - それ以外は市・町・村まで（`前橋市`、`箱根町`）
  - 名前の中に「市」「町」「村」「郡」の字を含む市区町村（例: 四日市市、町田市、大和郡山市、東村山市）も正しく分けること
- 残り: 市区町村より後ろ全部（そのまま）

例: `split_address("東京都千代田区丸の内1-1")` → `("東京都", "千代田区", "丸の内1-1")`

## 4. jpdata/zipcode.py — `normalize_zip(s: str) -> str | None`

郵便番号を `"NNN-NNNN"` の形にして返す。正しくなければ None。

- 先に normalize() する。先頭の `〒` と前後の空白は取る
- 7桁の数字、または3桁-4桁の形だけを受け付ける（`1000001`、`100-0001`）。それ以外（桁が違う、文字が混ざる、ハイフンの位置が違う）は None
